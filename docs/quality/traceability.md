## 强约束

- 本文件是需求注册表：没有矩阵行，就不是本版本 tracked requirement。
- `COVERED` 只允许用于有自动化证据且该行无已知缺口的需求。
- 没有自动化证据，或只有局部证据但仍有缺口，状态必须写 `GAP`。
- `manual` 是验证方式，不是自动化证据；仅有人工验证的需求状态仍为 `GAP`。
- 风险等级：低 / 中 / 高 / 极高。
- 验证方式：unit / property / integration / contract / e2e / manual。
