Where to find these
  1. Open the Discord developer portal → your application.
  2. Copy the Application ID from the General Information tab.
  3. In the Bot tab, click Reset Token and copy the new token.
  4. Under Privileged Gateway Intents, enable MESSAGE CONTENT.
  5. Invite the bot to your server with the OAuth2 URL generator using bot + applications.commands scopes.
