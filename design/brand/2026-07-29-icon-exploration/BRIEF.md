# Gian icon brief

## Product

- Gian is an AI IDE and the user's personal intelligent space.
- The name comes from Gian, the English name used for Doraemon's Takeshi
  Goda. The useful association is his inexhaustible drive, not a literal
  character likeness.
- The core metaphor is a door, entrance, or window into that personal space.

## Visual direction

- Prefer one strong, minimal geometric symbol over a detailed mascot.
- A `G` is optional. It should only appear when the geometry earns it.
- Color gradients are welcome as an AI signal, but should be contained and
  deliberate rather than becoming a generic rainbow wash.
- The Catpaw icon is the stronger reference: energetic gesture, bold black
  line, clear white shape, vivid field.
- The Kimi icon is also useful: monumental single mark, black/white contrast,
  and one controlled color accent.
- Avoid generic blue information-symbol language.
- There are no other declared visual red lines.

## Surfaces

The first identity system must work on:

1. macOS Dock
2. Desktop application
3. Web favicon
4. macOS menu bar

Website and wider brand applications are intentionally deferred.

## Round-one rule

Evaluate silhouette before color. The four concepts use the same palette and
are shown at 64, 32, and 16 pixels plus a monochrome menu-bar reduction.
Production assets remain unchanged until one direction is selected.
